# 规划规则

## 1. 默认假设

最低输入是目的地与天数。其他字段缺失时使用以下默认值，并在最终方案中公开：

| 字段 | 默认值 |
|---|---|
| 游玩强度 | 正常游 |
| 同行人 | 普通成年游客，1–2 人 |
| 预算 | 中等预算 |
| 市内交通 | 公共交通为主，明显节时处打车 |
| 每天时段 | 09:00–21:00，包含用餐和缓冲 |
| 抵离时间 | 完整游玩日；最后一天可裁剪 |
| 兴趣 | 城市代表性景点、历史文化、街区与当地饮食的均衡组合 |

不得因为缺少可选信息而只输出模板。先生成可执行初版，再说明哪些信息能进一步提高准确度。

## 2. 强度边界

下表是排程上限，不是必须填满的目标。游览时间不含用餐；交通时间包括等待和换乘估计。

| 强度 | 建议主要景点数 | 景点游览合计 | 市内交通合计 | 连续步行 |
|---|---:|---:|---:|---:|
| 轻松游 | 2–3 个 | 约 300 分钟以内 | 约 90 分钟以内 | 30–45 分钟后休息 |
| 正常游 | 3–5 个 | 约 420 分钟以内 | 约 120 分钟以内 | 60–90 分钟后休息 |
| 特种兵游 | 5–7 个 | 约 540 分钟以内 | 约 180 分钟以内 | 仍需保留吃饭与转场缓冲 |

排队、安检、接驳、找入口和停车都属于真实时间成本。热门景点至少留 20–40 分钟弹性；大型景区和跨区移动留更大缓冲。

## 3. 景点价值分级

综合评价，不要只按平台热度：

1. 城市代表性与不可替代性。
2. 与用户兴趣、同行人和季节的匹配度。
3. 实际体验质量与口碑稳定性。
4. 开放、预约和天气可行性。
5. 相对门票、排队、交通与体力成本。
6. 能否与其他高价值景点形成顺路组合。

将结果分为“必去 / 推荐 / 可选”，每项用一句话解释。商业化严重但仍有独特价值的地点可以保留，同时明确最佳时段和避坑方法。

## 4. 空间优先的路线算法

### 4.1 建图

把景点、住宿候选区、机场/车站视为节点。边应包含：

- 地图路线距离，而不只是直线距离；
- 计划时段下的步行、公交/地铁、打车时间；
- 换乘次数、步行接驳、预计等待与费用；
- 数据来源、查询时间和是否为估算。

### 4.2 聚类

优先按 15–30 分钟交通可达范围形成自然片区。地理方位只是解释标签，真正决策以交通时间为准。行政区相同不代表顺路，直线距离近也可能被河流、高速或山体分隔。

### 4.3 分配到天

- 每天选择一个主片区；当内容不足时连接一个相邻片区。
- 一天通常最多一次有方向的跨区移动，例如“城北 → 城中”，跨区后不再返回。
- 远郊核心景点优先安排独立半天/整天，避免与相反方向景点拼接。
- 受闭馆日、预约场次、日落和天气制约的节点先占位。
- 连住时优先选能降低多日总交通成本的住宿区，而非只离某一个景点最近。
- 最后一天的终点向返程车站/机场靠拢；需要回酒店取行李时把酒店作为必经节点重新计算。

### 4.4 日内排序

在满足开放和预约窗口后，最小化：

`总交通时间 + 折返惩罚 + 换乘惩罚 + 强度超限惩罚 + 返程风险惩罚`

排队敏感或大型户外景点通常放早晨；博物馆等室内项目可放炎热/降雨时段；夜景和夜市放最后。不要为了追求几分钟的数学最优而违反开放时间或降低体验。

## 5. 交通方式选择

- 步行：门到门通常不超过 15–20 分钟、道路适合且天气/体力允许。
- 公交/地铁：路线直接、班次稳定，且相对打车不会增加大量等待和换乘。
- 打车/网约车：可节省约 25–30 分钟以上、同行 3–4 人摊薄成本、携带行李、夜间或公共交通换乘复杂时。
- 包车/租车：只在郊区多点、公共交通明显不足且当地规则适合时建议；同时提示停车、驾照、保险和酒驾风险。

给出推荐方式与一个合理备选。距离、时间和费用要写成范围；只有来自可靠实时路线的数据才写精确值。

## 6. 特殊同行人

### 老人

减少台阶、连续步行和换乘；每天安排午休或酒店回撤可能；确认轮椅、电梯、景区接驳和医疗可达性。不要把“可以参观”误写成“无障碍友好”。

### 儿童

控制排队和讲解时长，增加互动项目、厕所和进餐频率；明确身高/年龄票务规则需以官方为准。

### 情侣、朋友

情侣可增加日落、夜景和慢节奏街区；朋友出行可保留更晚的夜生活，但不能压缩返程和安全缓冲。

## 7. 住宿、用餐与行李

住宿推荐区域至少比较：多日总交通、夜间回程、餐饮密度、枢纽连接、噪声和预算。推荐区域，不把未调研的具体酒店包装成结论。

每天推荐路线附近的用餐区域或菜品类型。网红店若需要明显绕路或排队，应给同类替代，不让餐饮破坏主路线。

退房后按优先级考虑：酒店寄存、车站/机场官方寄存、正规行李寄存服务。核验营业时间、尺寸限制和取件缓冲，不建议把行李留在无人看管处。

## 8. 天气与备选

- 雨天：室内场馆、可遮蔽街区、短转场；谨慎安排山水、夜景和长距离步行。
- 高温：户外提前，午后室内，补水与防晒；避免在最热时段长时间暴晒。
- 大风/雷电/冰雪：核验缆车、游船、山岳景区和航班/高铁影响。
- 闭馆：备用点应在同片区或回程方向，不能用一个跨城景点临时替换。

主方案中的关键节点至少准备一个同片区备选，并写明触发条件。

## 9. 预算

按住宿、餐饮、市内交通、门票、往返大交通、购物/机动金分类。写明人数、晚数、币种和不含项。范围估算优于虚假的精确总价；机动金通常预留可变支出的 10%–15%。
